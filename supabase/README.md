# Supabase

Projeto oficial: `https://ehsgzuelxqyxicmaqcic.supabase.co`

Nenhuma SQL deve ser aplicada nesta etapa. O diretorio esta preparado para receber migrations, functions e seeds versionadas apos desenho e revisao do modelo.

## Estrutura

- `migrations/`: migrations versionadas e imutaveis apos aplicacao.
- `functions/`: funcoes server-side quando necessarias.
- `seed/`: dados de apoio para ambientes controlados.
